# Every Door: Parks Plugin

A playground-focused Every Door plugin for OpenStreetMap.

## What it provides

* A dedicated **Playground** mode.
* Editing of `leisure=playground` polygons, and some ecouraged tags such as:
  `name`, `surface`, `wheelchair`, `playground:theme`, and
  `fenced`.
* Presets for all `playground=*` values currently documented by the
  OpenStreetMap `Key:playground` page, including an `Other playground
  equipment` option using `playground=user_defined`.
* Extra equipment fields such as `material`, `height`, `incline`, `capacity`,
  accessibility tags, sensory tags and `handrail`.
* Presets for common playground-related additional features:
  `amenity=bench`, `leisure=picnic_table`, `natural=tree`,
  `amenity=waste_basket`, `amenity=toilets` and `barrier=gate`.


## Install

The distributable file is `ed-playgrounds.edp`.

On your phone, open the `.edp` file with the Every Door app. The plugin is marked experimental while it is being developed & tested, eventually it will be available from the plugin library.
